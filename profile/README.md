# d1n-go

Go libraries and maintained forks.

- [2q](https://github.com/d1n-go/2q) — thread-safe generic 2Q cache for Go, a maintained fork of `floatdrop/2q` with `lru`/`fifo`/`list` vendored in as internal packages (zero external dependencies)
- [dbf](https://github.com/d1n-go/dbf) — Go library for reading DBF files
